# 硕士论文架构交接摘要

## 一、课题主线

当前课题方向为：机器视觉引导下的基于温度场的机器人增材制造自适应路径规划。

实验设备主要包括：

- 六轴机器人；
- 红外相机；
- 熔池相机；
- 打印头/热源系统；
- 送丝系统；
- 上位机与机器人控制器。

相机固定在机器人末端，随打印头运动。论文重点不是单纯调节激光功率或扫描速度，而是利用红外相机获取各打印分区的温度状态，根据温度场反馈动态调整每一层内各分区的打印顺序。

核心思路为：

```text
STL模型预处理
-> 分层切片
-> 每层分区
-> 每个分区生成候选路径
-> 第一层按默认顺序打印
-> 后续层采集红外温度场
-> 计算各分区温度特征
-> 根据温度状态决策下一打印分区
-> 生成或调用机器人运动指令
-> 机器人执行当前分区
-> 分区完成后再次测温并决策下一分区
```

推荐将论文主题表述为：

> 基于红外温度场感知的机器人增材制造分区自适应路径规划研究

或：

> 机器视觉引导下基于温度场反馈的机器人增材制造自适应路径规划方法研究

## 二、六章论文总体结构

论文缩减为六章，其中原先的 STL 切片路径生成和红外温度场评价两部分合并为第 3 章。第 4 章和第 5 章是重点章节。

整体结构为：

```text
第1章：绪论
第2章：机器人增材制造系统总体方案设计
第3章：模型预处理与分区温度场评价方法
第4章：基于温度场的分区自适应路径规划方法
第5章：实验平台搭建与方法验证
第6章：总结与展望
```

其中重点为：

```text
第4章：算法设计，是全文核心
第5章：实验验证，是论文说服力来源
```

## 三、第1章 绪论

### 1.1 研究背景与意义

主要说明机器人增材制造中固定路径打印容易导致局部热积累，热积累会引起成形尺寸误差、表面质量下降、组织不均匀、变形、塌陷等问题。

强调六轴机器人具有路径灵活性，红外相机可以在线获取温度场，因此可以利用温度场反馈调整打印顺序，从路径规划层面抑制热积累。

### 1.2 国内外研究现状

建议分为四类：

- 机器人增材制造路径规划研究；
- 增材制造过程温度场监测研究；
- 基于视觉或红外的增材制造在线控制研究；
- 基于热状态的路径优化与自适应规划研究。

### 1.3 现有研究不足

可总结为：

- 多数路径规划仍以离线固定路径为主；
- 温度场监测与路径规划之间耦合不足；
- 现有方法更多关注功率、速度调节，较少从打印顺序层面控制热积累；
- 移动红外相机获取的温度信息需要与分区路径建立空间对应关系；
- 缺少从 STL 预处理、分区路径生成、温度评价到机器人代码执行的完整流程。

### 1.4 本文主要研究内容

包括：

- 搭建机器人增材制造与红外视觉监测系统；
- 实现 STL 模型分层、分区和候选路径生成；
- 建立分区温度提取与热状态评价方法；
- 提出基于温度场的分区打印顺序自适应规划算法；
- 实现机器人运动代码生成与执行；
- 通过实验验证方法对热积累抑制和成形质量改善的效果。

### 1.5 论文组织结构

简要说明六章安排。

## 五、第3章 模型预处理与分区温度场评价方法

本章由模型切片、分区路径生成、红外温度场处理合并而来。它不是全文重点，但要为第 4 章自适应算法提供输入。

### 3.1 STL 模型预处理

包括：

- STL 文件读取；
- 三角面片数据结构说明；
- 模型坐标变换；
- 模型包围盒计算；
- 异常面片处理；
- 打印方向确定。

### 3.2 分层切片方法

层厚设为 `h`，第 `k` 层切片高度为：

```text
z_k = z_min + k * h
```

主要内容：

- 切片平面与三角面片求交；
- 交线段提取；
- 轮廓线排序；
- 内外轮廓判断；
- 切片轮廓闭合。

### 3.3 层内分区方法

建议优先采用容易实现且便于实验分析的网格分区或等面积分区。

每层可表示为：

```text
Layer_k = {R_1, R_2, ..., R_n}
```

每个分区包含：

```text
R_i = {Boundary_i, Area_i, Center_i, Path_i}
```

分区原则：

- 分区面积尽量接近；
- 避免过小区域；
- 保证每个分区内可生成连续路径；
- 保留分区邻接关系。

### 3.4 分区候选路径生成

每个分区内部生成候选路径，但打印顺序暂不固定。

可采用路径类型：

- 往复式扫描路径；
- Zigzag 路径；
- 轮廓偏置路径。

硕士论文建议主方法采用往复式扫描，表达清楚、实现难度适中。

路径点可表示为：

```text
Path_i = {P_1, P_2, ..., P_m}
P_j = [x_j, y_j, z_k]
```

### 3.5 红外温度图像处理

包括：

- 红外图像采集；
- 温度矩阵读取；
- 有效区域截取；
- 噪声滤波；
- 异常温度点剔除；
- 温度修正。

需要说明红外测温受材料发射率、相机角度、烟尘、飞溅和金属表面反射影响。

### 3.6 红外图像与分区区域映射

如果能完整标定，可写坐标转换链：

```text
Image -> IR_Camera -> Tool -> Base -> Workpiece
```

如果采用平面近似，可使用单应性矩阵：

```text
[x_w, y_w, 1]^T = H [u, v, 1]^T
```

其中：

- `[u, v]` 为图像像素坐标；
- `[x_w, y_w]` 为工件坐标；
- `H` 为图像平面到工件平面的单应性矩阵。

最终目标是得到每个分区对应的温度数据：

```text
T(R_i)
```

### 3.7 分区温度特征提取与评价

对每个分区提取：

```text
T_avg_i    平均温度
T_max_i    最高温度
T_min_i    最低温度
T_std_i    温度标准差
G_i        温度梯度
C_i        冷却速率
```

平均温度：

```text
T_avg_i = 1/N * sum(T(p))
```

最高温度：

```text
T_max_i = max(T(p))
```

温度标准差：

```text
T_std_i = sqrt(1/N * sum((T(p) - T_avg_i)^2))
```

可定义分区热状态评价指标：

```text
S_i = alpha * T_avg_i + beta * T_max_i + gamma * T_std_i
```

也可以把这些特征直接作为第 4 章综合代价函数的输入。

### 3.8 本章小结

总结本章完成从 STL 模型到分区候选路径、从红外图像到分区温度状态的转换。

## 六、第4章 基于温度场的分区自适应路径规划方法

本章是全文核心。

### 4.1 分区自适应路径规划问题描述

每一层包含多个分区：

```text
Layer_k = {R_1, R_2, ..., R_n}
```

每个分区具有路径和温度状态：

```text
R_i = {Path_i, T_avg_i, T_max_i, Start_i, End_i}
```

目标是确定当前层打印顺序：

```text
Order_k = [R_a, R_b, R_c, ...]
```

使热积累降低、温度更均匀，同时避免机器人空行程过大。

### 4.2 自适应打印顺序决策原则

包括：

- 过热分区延后打印；
- 温度接近目标范围的分区优先；
- 避免连续打印相邻高温分区；
- 距离机器人当前位置较近的分区优先；
- 保证所有分区最终完成打印。

### 4.3 分区综合代价函数设计

推荐作为核心公式：

```text
J_i =
w1 * |T_avg_i - T_target|
+ w2 * max(0, T_max_i - T_limit)
+ w3 * T_std_i
+ w4 * D_i
+ w5 * A_i
```

其中：

- `J_i`：第 `i` 个分区的综合代价；
- `T_avg_i`：分区平均温度；
- `T_max_i`：分区最高温度；
- `T_std_i`：温度离散程度；
- `D_i`：机器人当前位置到该分区入口点的距离；
- `A_i`：与上一打印分区的邻接惩罚；
- `T_target`：目标温度；
- `T_limit`：过热阈值；
- `w1 ~ w5`：权重系数。

选择规则：

```text
R_next = argmin(J_i)
```

### 4.4 温度约束与等待策略

当所有候选分区温度都过高时，不应强行打印，可以加入等待策略：

```text
if 所有候选分区均不满足温度约束:
    机器人移动到安全位置
    等待 Delta_t
    重新采集温度
```

温度约束可设置为：

```text
T_max_i < T_limit
T_avg_i in [T_low, T_high]
```

### 4.5 层内自适应规划算法

伪代码：

```text
输入：当前层分区集合 R，机器人当前位置 P，温度阈值
输出：当前层打印顺序 Order

Order = []

while R 不为空:
    采集红外温度图像
    计算未打印分区温度特征
    for 每个未打印分区 R_i:
        计算温度代价
        计算运动距离代价
        计算邻接惩罚
        得到综合代价 J_i
    if 所有分区均不满足温度约束:
        执行等待策略
        continue
    选择 J_i 最小的分区 R_next
    生成 R_next 的机器人运动代码
    发送机器人执行
    Order.append(R_next)
    从未打印集合中删除 R_next
    更新机器人当前位置
end while
```

### 4.6 层间热状态反馈策略

当前层结束后保留温度历史：

```text
T_history_k = {T_avg_i, T_max_i, cooling_i}
```

下一层可根据上一层热状态初始化打印顺序：

- 上一层高温区域在下一层延后；
- 上一层低温区域在下一层优先；
- 层间最高温度超过阈值则等待冷却。

### 4.7 机器人运动代码生成与在线发送

路径点转换：

```text
P_robot = T_base_workpiece * P_slice
```

机器人运动代码内容：

- 安全位姿；
- 分区入口点；
- 激光开关；
- 送丝开关；
- 扫描路径点；
- 分区结束点；
- 回安全高度。

KUKA 风格示例：

```text
PTP P_SAFE
LIN P_START
Laser_ON
Wire_ON
LIN P1
LIN P2
LIN P3
Laser_OFF
Wire_OFF
PTP P_SAFE
```

### 4.8 本章小结

总结提出了温度驱动的分区打印顺序自适应算法，并完成了路径决策到机器人执行代码的转换。

## 七、第5章 实验平台搭建与方法验证

本章是论文第二重点，用于证明方法有效。

### 5.1 实验平台与材料

介绍：

- 机器人型号；
- 热源系统；
- 送丝系统；
- 红外相机参数；
- 熔池相机参数；
- 机器人通讯方式；
- 打印材料；
- 基板材料；
- 保护气体；
- 实验环境。

### 5.2 实验方案设计

建议设置三类实验：

- 温度场采集与分区温度评价实验；
- 固定路径与自适应路径对比实验；
- 不同分区数量或不同权重参数对比实验。

### 5.3 温度场采集与分区评价实验

验证第 3 章方法：

- 红外图像是否能映射到分区；
- 分区平均温度是否能反映热状态；
- 打印过程中各分区温度如何变化；
- 不同区域冷却速度是否不同。

结果形式：

- 红外温度云图；
- 分区温度柱状图；
- 温度随时间变化曲线。

### 5.4 固定路径与自适应路径对比实验

核心实验。

对比：

```text
方法A：固定顺序打印
方法B：温度场自适应分区顺序打印
```

评价指标：

```text
最高温度 T_max
平均温度 T_avg
温度标准差 T_std
热积累区域面积
成形高度误差
成形宽度误差
表面质量
打印总时间
```

需要证明：

- 自适应路径降低了局部峰值温度；
- 层内温度更均匀；
- 成形尺寸波动更小；
- 代价是可能增加一定空行程或打印时间。

### 5.5 分区数量对规划效果的影响

比较：

```text
2分区
4分区
6分区
8分区
```

分析：

- 分区过少，自适应能力不足；
- 分区过多，路径切换和空行程增加；
- 存在较优分区数量。

### 5.6 权重参数对规划结果的影响

比较不同权重组合：

```text
温度优先型
距离优先型
均衡型
```

分析：

- 温度优先可以更好抑制热积累；
- 距离优先可以减少打印时间；
- 均衡策略综合效果较好。

### 5.7 成形质量检测与分析

可包括：

- 宏观形貌；
- 表面质量；
- 高度和宽度尺寸测量；
- 截面形貌；
- 显微组织；
- 硬度测试。

如果条件有限，至少建议完成：

```text
宏观形貌 + 尺寸误差 + 截面形貌
```

### 5.8 实验结果讨论

重点讨论：

- 自适应路径为什么能降低热积累；
- 温度控制和运动效率之间的矛盾；
- 分区大小对效果的影响；
- 红外测温误差对决策的影响；
- 方法适用范围和局限性。

### 5.9 本章小结

总结实验验证结果。

## 八、第6章 总结与展望

围绕论文主线总结：

- 设计了机器人增材制造视觉监测系统；
- 实现了 STL 分层、层内分区和候选路径生成；
- 建立了分区红外温度场评价方法；
- 提出了基于温度场的分区自适应路径规划算法；
- 实现了机器人运动代码生成；
- 通过实验验证了热积累抑制和成形质量改善效果。

### 6.2 主要创新点

建议写三点：

- 提出了一种面向机器人增材制造的层内分区路径规划框架；
- 建立了红外温度场与打印分区对应的热状态评价方法；

### 6.3 不足与展望

可以写：

- 红外相机测温受发射率和飞溅影响，后续可进行更精确温度修正；
- 熔池相机信息尚未深度参与控制，后续可融合熔池形态进行多模态闭环；
- 当前主要针对平面分层，后续可扩展到曲面分层和非平面增材；
- 后续可引入模型预测控制、强化学习或数字孪生方法。

## 九、机器人指令转换与动态改变执行顺序方案

当自适应打印顺序已经决策完成后，不建议在机器人高速运动中强行修改正在执行或已经进入缓冲区的轨迹。更稳妥的方式是将原始固定路径拆分为多个可独立调用的分区轨迹块，通过改变轨迹块执行顺序实现路径自适应。

### 9.1 推荐实现方式：预生成分区子程序，动态调用

离线阶段为每一层、每个分区生成独立子程序：

```text
L2_R1.src
L2_R2.src
L2_R3.src
L2_R4.src
```

每个子程序只负责一个分区内部路径，例如：

```text
DEF L2_R3()

PTP P_SAFE
LIN P_L2_R3_START

Laser_ON
Wire_ON

LIN P_L2_R3_001
LIN P_L2_R3_002
LIN P_L2_R3_003

Laser_OFF
Wire_OFF

PTP P_SAFE

END
```

自适应算法决策后得到：

```text
打印顺序 = [Region_3, Region_1, Region_4, Region_2]
```

机器人端按照这个顺序调用对应子程序：

```text
L2_R3 -> L2_R1 -> L2_R4 -> L2_R2
```

### 9.2 机器人主程序结构

主程序不固定写死打印顺序，而是等待上位机发送下一分区编号：

```text
DEF MAIN()

LOOP
    等待上位机发送 region_id

    IF region_id == 1 THEN
        L2_R1()
    ENDIF

    IF region_id == 2 THEN
        L2_R2()
    ENDIF

    IF region_id == 3 THEN
        L2_R3()
    ENDIF

    IF region_id == 4 THEN
        L2_R4()
    ENDIF

    IF region_id == 0 THEN
        EXIT
    ENDIF
ENDLOOP

END
```

实际通讯方式可根据设备条件选择：

- TCP/IP；
- KUKA EKI；
- KUKA RSI；
- PLC 中转；
- 文件交换；
- 数字 IO 编码；
- 机器人控制器外部自动模式接口。

### 9.3 上位机与机器人握手流程

建议使用分区间握手机制：

```text
1. 机器人发送 READY
2. 上位机发送 region_id = 3
3. 机器人执行 L2_R3
4. 机器人发送 DONE
5. 上位机采集红外温度
6. 上位机计算下一分区
7. 上位机发送 region_id = 1
8. 机器人执行 L2_R1
```

自适应决策发生在分区之间，而不是分区内部某条运动指令执行到一半时。

分区结束时应设置明确决策点：

```text
分区打印完成
-> 激光关闭
-> 送丝关闭
-> 机器人抬高到安全高度
-> 等待上位机指令
-> 执行下一分区
```

### 9.4 论文中的推荐表述

可以写为：

> 本文采用基于分区轨迹块的机器人指令重构方法。首先将每层打印路径按照分区划分为若干独立轨迹块，并分别生成机器人可执行子程序。打印过程中，上位机根据红外温度场计算各未打印分区的综合代价，确定下一打印分区编号，并通过通讯接口发送至机器人控制器。机器人主程序根据接收到的分区编号调用对应轨迹子程序，从而实现对原有固定打印顺序的动态重排。

### 9.5 最小可行实现建议

推荐第一版系统采用：

```text
离线生成每个分区的机器人子程序
上位机只发送分区编号
机器人端根据编号调用子程序
每个分区结束后暂停等待下一命令
```

这种方式轨迹安全性高、控制逻辑清楚、容易调试，适合硕士论文实验落地。
